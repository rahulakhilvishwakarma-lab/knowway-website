# Knowway website

The static website homepage is `index.html`. The site uses the shared `styles.css`
and the local images in `assets/`.

## Pages

- `index.html` — Knowway introduction and supported app features
- `about.html` — About Knowway
- `how-it-works.html` — How the discovery and trip-planning flow works
- `contact.html` — Contact information
- `privacy-policy.html` — Privacy policy draft
- `terms-and-conditions.html` — Terms draft

The Google Play listing is not available yet; the homepage marks it as coming soon.
The older `assets/index.html` path redirects to the root homepage.

To preview locally, serve this directory with any static web server and open
`index.html`. No build step or external frontend dependencies are required.
