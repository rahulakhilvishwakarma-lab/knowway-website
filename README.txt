KNOWWAY WEBSITE — READY-TO-UPLOAD PACKAGE

This is a standalone static website package for the separate knowway-website GitHub repository. It does not contain or modify the Android app.

CONTENTS
- index.html: complete responsive landing page
- assets/knowway-logo.png: horizontal Knowway logo sourced from the supplied project ZIP
- assets/knowway-icon.png: Knowway app icon, also used as favicon
- assets/heritage-monument.jpg: heritage visual from supplied project assets
- assets/goway-journey.png: scenic GoWay journey visual from supplied project assets

FEATURE SECTIONS
- Nearby
- Bharatverse
- GoWay Corridor and GoWay Layover
- Trip Cart
- Discover India inspiration
- How it works
- About, privacy information, and contact
- Separate Google Play callout

IMPORTANT BEFORE DEPLOYMENT
1. Upload the CONTENTS of this folder into the root of the separate knowway-website repository (not the Android app repository).
2. The Google Play button intentionally does not point to a fake URL. Replace it with the official Play Store URL when the listing is available.
3. The Privacy section is a short informational summary, not a substitute for the full official privacy policy. If you have a published privacy-policy URL, add it to the footer and link it here.
4. Confirm Vercel deploys the website repository and that knowway.in is assigned to the intended Vercel website project before changing any domain settings.
5. Google Search snippets and favicon updates are controlled by Google and may take time after deployment.

The site uses relative local asset paths and should work as a static site on Vercel or GitHub Pages. No build step is required.
